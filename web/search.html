安吾アトラス

一節から探す — ある段落を起点に、他の作品の近い一節へ渡り歩く

語の索引は名詞だけを収めている(2 文字以上、または 1 文字の漢字。数詞は除く)。 埋め込みが苦手な固有名詞を補うための機能なので、活用する語は入っていない。

近い一節

この機能について

「一節から探す」はクエリのたびにモデルを動かさない。全 15,430 の一節を前もって ベクトルにしてあり、起点の一節のベクトルとの内積を取るだけで近傍が出る。だから サーバーも API も要らない。ベクトルは 次元 float16(5.43 MB)で、 原次元との近傍一致率は 0.9815(2026-08-25 実測)。

同じ作品からの結果は最大 2 件に抑えている。新字新仮名版と新字旧仮名版の両方がある作品は 片方だけを検索対象にしている( 作品を除外)。リーダーでは両版とも読める。
