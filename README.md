# 安吾アトラス(ango-atlas)

**本番: https://ango-atlas.vercel.app**(L7 で公開予定)

青空文庫収録の坂口安吾コーパスを、**文体・主題・時系列・言及**の四軸で俯瞰する静的 Web アプリ。
クラスタや統計そのものではなく「同クラスタ内の近傍作品」「クラスタ境界の作品」、そして
**任意の一節から他作品の一節へ渡り歩く**経路を見せることで、読書案内として機能させる。

6 ビュー構成: 年表・作品一覧 / 文体マップ / 主題マップ / 一節から探す / 転換点 / リーダー。
作品 ID とチャンク ID を共通キーとして相互リンクする。詳細は [SPEC.md](SPEC.md)、
構想の背景と設計判断は [docs/CONCEPT.md](docs/CONCEPT.md)。

## 設計上の中心的判断

サーバー・API を持たない(N-01)ため、目玉機能の一節検索は**クエリ時にモデル推論を必要としない**
設計にした。段落クリックを起点にすれば、必要なのは事前計算済みベクトルの内積だけで済む。
自由語は BM25 の静的転置索引が担い、自由語の意味検索だけを遅延ロード・オプトインの追加機能
(F-25)として最後に置く。

## 検証オラクル

背骨は **O-1「二重版一致」**。青空文庫の安吾コーパスには同一作品の新字新仮名版と新字旧仮名版が
両方あるタイトルが存在し、これは「同じ文体・同じ内容で表記だけが異なる」ラベル無しの正解対である。
文体特徴量が表記を拾っていれば必ずクラスタが割れるため、前処理と特徴量の妥当性を自動検証できる。
ほかに往復検査(O-2)、既知近傍(O-3)、ARI(O-4)、量子化損失(O-5)。詳細は [TEST_SPEC.md](TEST_SPEC.md)。

## ディレクトリ

```
pipeline/   取得・パース・前処理・特徴量・埋め込み(Python, オフライン)
data/       実測データ(provenance 付き)。data/cache/ は git 管理外
web/        静的サイト(Vercel outputDirectory)
tests/      pytest。マーカー unit / integration / validation
docs/       構想・較正記録・モデル選定根拠
logs/loops/ ループログ(loop-observability)
```

## ループ計画

| ループ | 内容 | 要求 |
|---|---|---|
| L1 | 作家ページ実測・本文取得・パーサー・往復検査 | F-01..04 |
| L2 | メタデータ・二重版ペア表・旧仮名正規化 | F-05..07 |
| L3 | 文体特徴量 → クラスタ → 文体マップ + 年表 + リーダー(**初回デプロイ**) | F-08..12 |
| L4 | チャンク分割・埋め込み 2 モデル比較・圧縮決定 | F-13..15 |
| L5 | 一節から探す + BM25 自由語検索 + 版重複排除 | F-16..18 |
| L6 | 主題マップ・転換点・言及グラフ | F-19..22 |
| L7 | 相互リンク統合・固定フッタ・app-menu 掲載・GitHub 公開 | F-23..25 |

L3 で一度出荷するのは安全側の切り方で、埋め込みが不発でも「文体マップ + リーダー」だけで
作品として成立させるため。
